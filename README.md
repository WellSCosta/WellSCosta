# Wellington Costa

**`Desenvolvedor Back-end`**


Desenvolvedor Backend focado no ecossistema Java (Java 21, Spring Boot 3.x) com experiência prática na construção de microsserviços escaláveis, arquiteturas orientadas a eventos e integração com IA generativa.

Meu foco não é apenas escrever código, mas resolver problemas de negócios utilizando boas práticas (Clean Code, SOLID, testes automatizados com JUnit/Mockito). Tenho vivência prática no desenvolvimento de sistemas de alta volumetria utilizando mensageria com Apache Kafka (incluindo resiliência com DLQ), caching com Redis, e deployments containerizados com Docker.

Em meus projetos recentes (como o SmartStock AI e The Pulse), apliquei conceitos avançados como rastreabilidade distribuída (Correlation IDs) e Locks Otimistas (JPA) para garantir integridade de dados em ambientes concorrentes. Busco sempre construir APIs seguras, bem documentadas (Swagger/OpenAPI) e orientadas a performance.
